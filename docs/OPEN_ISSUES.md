## 当前无本地阻塞项

P2–P5 主流程已在本地通过真实 MyBatis 文档和 Qwen API。以下事项不阻塞本地使用，但进入 P6 公网部署或扩大材料范围前需要处理。

| ID | 优先级 | 事项 | 当前影响 | 处理条件/建议 |
| --- | --- | --- | --- | --- |
| O-001 | 高 | 轮换曾在截图和 CSV 中暴露的 API key | 本地仍可调用，但旧 key 不应进入公开部署 | 用户在供应商控制台轮换后重新运行 `config:import` |
| O-002 | 高 | 公共 URL 允许地址未经过生产网关端到端验证 | 当前网络把公共域名映射到 `198.18.0.0/15`，网关正确拒绝；文件主流程不受影响 | 在普通本机网络或 P6 部署环境验证允许 URL、重定向到私网、超时和超限 |
| O-003 | 中 | 模型费用单价与公开预算未知 | 已记录 token/延迟，但不能计算实际单次成本 | P6 前取得供应商价格，设置日预算、限流和必要的访问口令 |
| O-004 | 中 | 关闭 thinking 后的路线质量样本较少 | 两组 MyBatis 画像通过，长期泛化尚未证明 | 用 RFC 和大型教程扩大回归，只有质量收益明确时再开启 thinking |
| O-005 | 中 | 关键词检索对同义改写和跨章节推理有限 | 固定 MyBatis/RFC 基准 10/10，开放式追问仍可能证据不足 | 先扩充非原词回归；若失败率明显再评估混合 Embedding，不提前引入向量库 |
| O-006 | 低 | OCR、公式、图表与截图语义不支持 | 截图型 PDF 显示质量告警，不阻塞文本型材料 | 作为后续独立范围评估，不用图片协议探针冒充已支持 |

| O-008 | 中 | 合法引用 ID 不等于逐句语义被来源支持 | 已收紧 policy 提示，但模型仍可能把通用背景与片段结论混合 | 增加 RFC/MyBatis 逐句支持度样本与人工评分；必要时把“文档事实”和“补充解释”结构化分栏 |
| O-009 | 低 | 是否需要长期历史、数据库与登录 | 当前新建精读只创建新的内存会话，旧会话不可从 UI 找回 | `v0.2` 不做；只有出现跨设备、长期恢复或真实多用户目标时进入 `v0.4` 评估 |
| O-010 | 低 | 是否增加中文开发诊断面板 | Next.js 开发工具已关闭；公网 Demo 缺少模型延迟和引用数量等诊断入口 | 仅在 P6 调试或交付证据需要时实现，环境变量控制且生产默认关闭 |

## 已在开发中解决的问题

- 长目录逐字匹配不稳定：改为服务端 `SC` 编号映射。
- Qwen 术语表对象/数组差异：增加等价结构归一化。
- 路线单次 59 秒：关闭 thinking、缩减代表片段后降至 11 秒。
- 流式中断污染状态：采用临时 token + 完整结束后原子提交。
- PDF 依赖安全公告：升级 `pdfjs-dist`，最终依赖审计为 0。
- `127.0.0.1` 首次会话被同源校验误拒：改用真实 Host/协议比较并补回归测试。
- 完成首阶段后刷新回到第一项：新增阶段优先级规则并验证恢复到下一待开始阶段。

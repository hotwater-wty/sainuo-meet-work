# P3 实施设计

- 日期：2026-09-02
- 状态：已完成
- 目标：生成画像驱动、可解释并受来源约束的文档地图与阅读路线

## 模型与规则职责

| 能力 | 模型负责 | 服务端负责 |
| --- | --- | --- |
| 文档地图 | 提炼目的、核心问题、术语和结论 | 注入真实分类、解析限制并校验 Schema |
| 阅读路线 | 根据目标、熟悉程度和关注点安排 3–6 阶段 | 分配 ID、限制来源范围、保存状态 |
| 来源定位 | 不直接创建引用对象 | 本地检索、真实块 ID、页码/标题和摘录映射 |
| 大书处理 | 在用户选择范围内组织路线 | 未选范围时拒绝请求 |

结构化响应第一次校验失败时，服务端只携带 Schema 错误和原输出请求修复一次。第二次失败返回可重试错误，不保存半成品路线。

## 输入预算

- 最多发送 80 个目录候选和均匀抽样的代表片段。
- 单次结构摘要控制在约 14,000 字符内，不发送整篇文档。
- 约束型材料在系统提示中强制使用“该文档规定”的口径。
- 服务端把真实范围映射为 `SC01` 等短编号；模型只能返回编号，保存前再映射回真实标题，未知编号被拒绝。

## 引用预览

阶段来源预览以阶段标题、目标和来源范围作为检索查询。MiniSearch 对标题、代码和正文加权，同时保留英文标识符与中文 bigram。接口只返回 `Citation`：真实块 ID、服务端标签、截断摘录、页码和标题路径。

## 验证门槛

- 三种目标、三种熟悉程度均可通过 Schema。
- 同一材料的 `overview/new` 与 `implementation/experienced` 路线重点可说明地不同。
- `book` 未选范围返回业务错误。
- 模型未知来源范围、无效枚举和超过 6 阶段均不能保存。
- 来源抽屉所有 ID 都存在于当前来源块；无结果时明确返回证据不足。

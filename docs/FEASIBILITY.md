# 技术文档精读助手可行性分析

- 版本：`v0.2`
- 状态：P1 已验证
- 日期：2026-09-01

## 1. 结论

方向可行，且比通用学习助手更适合本次作业：用户、材料、任务和最终成果都更明确，RAG、分阶段交互和文件生成也有自然理由。P1 已用真实混合材料、RFC 6455 和 `qwen3.6-flash` 验证文本主链路，详细证据见 `docs/archive/P1_VALIDATION.md`。

已选择的完整演示版合理投入为 1–2 个完整开发日。它高于题目建议的 4–6 小时，但仍满足 1–2 天交付窗口。若实际时间收紧，应首先缩减 URL 导入和格式覆盖，不牺牲引用可信与笔记确认闭环。

## 2. 产品可行性

### 优势

- 技术规范的概念依赖、约束和例外确实不适合一次摘要。
- 阅读目标与熟悉程度容易形成可见的个性化差异。
- 引用正确性、阶段状态和笔记确认都可客观验收。
- 用户自有资料可用于真实展示，公开 RFC 可用于可复现测试。

### 局限

- 一次 Demo 只能验证过程是否清晰，不能证明长期开发效率提升。
- 技术文档格式差异大，无法承诺复杂表格、图形和扫描件的高保真理解。
- 没有主动搜索时，产品只能解释当前文档，不能自动补齐最新版本或外部背景。

## 3. 技术可行性

| 能力 | 可行性 | 主要风险 | 首版控制方式 |
| --- | --- | --- | --- |
| PDF/MD/TXT/HTML 解析 | 高 | 复杂排版、扫描件、代码块丢失 | 只承诺文本型文档并显示解析告警 |
| 公开 URL 导入 | 中高 | SSRF、动态页面、重定向、超大响应 | 受控网络访问、静态正文、严格上限 |
| 文档地图与路线 | 高 | 结构化输出不稳定 | Schema 校验、一次修复、显式失败 |
| 本地检索 | 高 | 同义词召回弱 | 章节、标识符、中文 bigram 混合评分 |
| 引用校验 | 高 | 模型伪造 ID | 只映射本轮服务端发放的来源 ID |
| 流式阶段讲解 | 中高 | 中断导致状态错误 | 流完成后才提交阶段结果 |
| 确认式笔记 | 高 | 重试重复写入 | 草稿 ID 与幂等接受操作 |
| 公网部署 | 中高 | 内存会话、滥用、费用 | 单实例、TTL、限流、预算上限 |

P1 已验证 `qwen3.6-flash` 的结构化文本、SSE 和 OpenAI 风格图片输入协议。图片请求成功不代表 OCR 或复杂图表理解，因此截图型 PDF 仍保持“解析质量告警 + 暂不支持”的产品表现。

## 4. 范围与时间

### 完整演示版：1–2 个开发日

- 四种文件格式和受控 URL 导入。
- 文档地图、阅读画像和 3–6 阶段路线。
- 本地检索、引用抽屉和阶段讲解。
- 草稿编辑/接受/跳过与 Markdown 导出。
- 自动化测试、Docker 和公网部署。

### 时间不足时的降级顺序

1. URL 只支持静态 HTML，不支持远程 PDF。
2. 上传格式缩减为 PDF、Markdown 和 TXT。
3. 只提供一个预置材料和一条固定演示路线。
4. 移除可选 Embedding 接口。

不得降级的部分是：来源校验、阶段状态正确性、用户确认后写入笔记，以及无材料不聊天的产品边界。

## 5. 成本

主要成本是模型输入/输出和长驻托管服务。本地检索不产生 Embedding 费用。

控制方式：

- 提取文本上限 500,000 字符。
- 文档地图只使用结构摘要和代表片段，不发送无限全文。
- 每轮只提供少量相关来源片段。
- 公开 Demo 设置模型请求频率、单日总量和供应商预算上限。
- 在用户资料到位后实测一次完整流程的 token、延迟和费用。

## 6. 隐私、版权与安全

- 用户必须有权处理和展示上传材料。
- 页面披露来源文本会发送给配置的模型供应商。
- 原文件不永久保存，提取内容随会话过期清理。
- URL 导入不得访问私网、云元数据地址或本机服务。
- 网页和文档内容视为不可信数据，不能覆盖系统指令或触发工具。
- 日志只记录请求 ID、耗时、状态、用量和错误类别。

## 7. 上线判断

首版采用单体长驻 Node 容器和单实例运行，因为匿名会话、来源块与阶段状态保存在进程内。传统多实例 Serverless 可能让连续请求访问不同内存，不能作为首选。

公开上线前必须确认：模型预算、限流、健康检查、HTTPS、环境变量保护、演示期限和下线方式。

## 8. 主要风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 用户资料无法解析 | 主 Demo 失败 | 开发第一阶段先做资料准入测试，保留 RFC 回归材料 |
| URL 导入存在 SSRF | 服务端资源暴露 | DNS/IP 校验、协议白名单、受控重定向和大小限制 |
| 路线只是目录复述 | 差异化不足 | 强制关联阅读目标、前置关系和推荐理由 |
| 模型曲解规范 | 错误学习 | 引用定位、证据不足提示和用户确认草稿 |
| 流式中断污染状态 | 阶段与笔记错误 | 完整结束后原子提交，接受操作幂等 |
| 公网滥用 | 费用失控 | 限流、预算、输入限制和必要时访问口令 |
| 范围再次扩张 | 无法按时交付 | 以 `PLANNING.md` 阶段门槛和变更规则控制 |

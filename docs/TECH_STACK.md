# 技术选型说明

- 版本：`v0.2`
- 状态：P5 本地实现完成
- 日期：2026-09-01

## 1. 选型原则

- 一套应用完成页面、API 和部署，减少交付面。
- 业务状态由应用显式维护，不把流程正确性完全交给模型。
- 引用可信和输入安全优先于复杂 RAG 算法。
- 依赖规模与单文档、临时会话的首版边界相匹配。
- 模型供应商可替换，但首个验证基线明确。

## 2. 应用与界面

- Next.js `16.3.4` App Router + React `19.2.8` + TypeScript。
- Route Handlers 提供上传、URL 导入、路线、阶段和导出接口。
- Zod 校验客户端输入、内部模型和模型结构化输出。
- 原生 CSS 变量/CSS Modules 构建设计系统，不引入大型组件库。
- `lucide-react` 提供图标。
- 工作区以文档地图、阶段内容、笔记和来源抽屉为主要界面，不制作营销落地页。

## 3. 文档解析

- PDF：`pdfjs-dist`，按页提取文本并保留页码。
- Markdown：`remark-parse` 提取标题、段落和代码块。
- TXT：UTF-8 文本与段落编号。
- HTML 文件和 URL：`linkedom` + `@mozilla/readability` 提取正文，再保留标题层级和代码文本。
- 不执行导入 HTML 中的脚本，不直接渲染不可信 HTML。
- OCR、图片、公式和复杂表格不在首版支持范围。

## 4. URL 获取

- 使用 Node/Undici 发起服务端请求。
- 仅允许 HTTP/HTTPS；禁止 URL 凭据。
- 初始请求及每次重定向都解析 DNS 并拒绝回环、私网、链路本地、保留地址和云元数据目标。
- 最多 3 次重定向、15 秒超时、10 MB 响应上限。
- 只接受 `text/html`、`text/plain`、Markdown 和 PDF 类型。
- 不运行无头浏览器；动态页面正文不足时要求用户上传导出文件。

## 5. 模型与响应

- 默认使用用户提供的 OpenAI-compatible Qwen API，首个模型为 `qwen3.6-flash`。
- 开发阶段如需切换模型，只允许使用同一服务中的 Qwen 系列；其他供应商或模型必须先更新设计基线。
- 环境变量：`LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`。
- `ModelClient` 隔离供应商协议、超时、重试和用量统计。
- 文档地图、路线和笔记草稿使用非流式结构化响应并通过 Zod 校验。
- 阶段讲解使用 SSE 流式响应；服务端收到完整成功结果后才提交状态。
- 测试使用确定性的 Fake Model Client，不依赖真实费用。
- 视觉输入不是首版依赖：P1 记录 `qwen3.6-flash` 的视觉兼容性；若不支持，截图型文档只报告解析降级，不阻塞文本型主流程。

## 6. 本地检索

- `MiniSearch` 建立会话级倒排索引。
- 拉丁单词、规范关键词、标识符保持原样；中文同时生成字符 bigram。
- 章节标题、代码标识符和正文使用不同权重。
- 文本块按标题/页码边界切分，目标约 800–1,200 字符，重叠约 150 字符。
- 首版不使用向量数据库，不要求 Embedding 服务。
- 保留 `EmbeddingProvider` 接口，后续可做混合召回，但不进入 v0.2 实现门槛。

## 7. 状态与存储

- 进程内 TTL Store 保存匿名会话、来源块、阅读画像、路线、阶段和确认笔记。
- 会话最后活动 2 小时后清理。
- 一个会话一份活动文档；服务单实例运行。
- 草稿接受使用唯一草稿 ID 和幂等写入，防止重复提交。
- 原始二进制只在解析期间存在，不写入长期目录。

## 8. 测试与质量

- Vitest：解析适配器、分块、检索、URL 安全、状态机、引用校验和 Markdown 导出。
- React Testing Library：阅读画像、笔记确认和来源抽屉。
- Playwright：完整 Demo、错误恢复、桌面和移动端。
- ESLint + TypeScript：静态检查。
- 测试夹具使用公开 RFC 节选和自建安全样例，不提交用户敏感资料。

## 9. 部署

- Next.js standalone 多阶段 Docker 镜像。
- 部署到 Render Web Service 或同类长驻容器平台，单实例运行。
- `/api/health` 只返回存活和版本，不返回供应商或密钥信息。
- 平台注入环境变量，启用 HTTPS、请求限制和模型预算。
- Vercel Serverless 不作为首选，除非会话状态先迁移到外部存储。

## 10. 暂不引入

- LangChain、LlamaIndex、向量数据库、ORM 和数据库。
- FastAPI 独立服务、无头浏览器、OCR 服务。
- Agent 框架、外部搜索和代码执行沙箱。

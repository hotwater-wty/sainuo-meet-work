# P5 实施设计

- 日期：2026-09-02
- 状态：已完成
- 目标：把用户认可的阶段理解沉淀为可下载 Markdown

## 草稿与决议

1. 只有 `awaiting_note` 阶段可以创建草稿。
2. 模型返回结构化要点，服务端渲染固定 Markdown 小节；文档内容不能改变模板。
3. 同一阶段只创建一个草稿；重复生成直接返回现有草稿。
4. `accept` 必须提交用户当前编辑内容；`skip` 不写入最终成果。
5. 相同动作重试幂等返回，冲突动作返回 409。
6. 接受或跳过后阶段变为 `completed`，下一阶段才允许开始。

## 导出结构

- 来源元数据
- 阅读画像
- 一分钟概览
- 核心术语
- 已接受阶段笔记（机制、约束、示例、陷阱、待追问）
- 真实引用索引

导出忽略 `pending` 和 `skipped` 草稿。文件名由服务端生成；原生危险 HTML 与 `javascript:` 链接被中和。

## 验证门槛

- 重复创建草稿不产生第二个 ID 或模型调用。
- 编辑内容按用户提交值保存，重复接受不重复加入。
- 跳过后阶段完成但导出不含该草稿。
- 冲突决议不能覆盖既有结果。
- 导出引用只来自对应阶段已保存的真实 `Citation`。
- 下载头包含安全 ASCII 回退名和 UTF-8 文件名。
